# Dataset provenance

Bitext Innovations, Customer Service Tagged Training Dataset for LLM-based Virtual Assistants, 27K responses v11.

Source repository: https://github.com/bitext/customer-support-llm-chatbot-training-dataset
Source CSV: data/Bitext_Sample_Customer_Support_Training_Dataset_27K_responses-v11.csv
Git blob: 404649b80bb5ec57463d7ce7e17bc48e63b01fbc
Dataset card: https://huggingface.co/datasets/bitext/Bitext-customer-support-llm-chatbot-training-dataset

The included bitext_intents.jsonl is a derived projection of all 26,872 source rows. It keeps source-row number, flags, instruction (renamed text), category and intent. Response text was omitted because ShopAssist uses its own deterministic responses and fictional store policy, not the dataset's generic generated responses. The original data is synthetic/hybrid NLG data curated by Bitext, not a collection of live conversations with this app.

The Bitext-derived data remains subject to the included data/LICENSE.txt (CDLA-Sharing 1.0). The project's application-code license does not replace the dataset license. Retain attribution and the data license when redistributing the source or splits.

Authored supplement: supplement.jsonl is generated by augment.py, documented separately from Bitext. The training script excludes supplement sentences whose normalized text occurs in the Bitext validation or test sets. The fixed Bitext split removes duplicate normalized utterances before splitting. Template-related paraphrases may still cross partitions; reported synthetic-data metrics are optimistic.

train.jsonl mixes attributed Bitext-derived records and explicitly marked authored training supplements. validation.jsonl and test.jsonl contain only held-out Bitext-derived records. The standalone challenge in evaluate_challenge.py is author-written and was not used in model fitting or threshold selection.
